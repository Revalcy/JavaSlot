# JavaSlot 

A simple text-based **Java slot machine game**. Place bets, spin the reels, and see if you can hit the jackpot!

## Features

- User-defined starting balance
- Input validation for bets and starting balance
- 3 reels with 5 symbols: 🍒 🍉 🍋 🔔 ⭐
- Payouts:
  - **3 of a kind:** 🍒 x3, 🍉 x4, 🍋 x5, 🔔 x10, ⭐ x20
  - **2 of a kind:** 🍒 x2, 🍉 x3, 🍋 x4, 🔔 x5, ⭐ x10
- Small jackpot chance (0.1%) that multiplies your current balance
- Replayable until balance runs out
